# NGU Lingo Companion (放置游戏英语伴侣)

专门为 **NGU IDLE** 以及其他挂机/放置类（Incremental/Idle）游戏量身打造的桌面英语学习助手。

---

## 🌟 为什么需要这款工具？

1. **Unity 游戏文字无法直接复制**：NGU IDLE 里的所有装备描述、转生机制、Boss 剧情都不能用鼠标选中文本复制。本软件支持**全局快捷键 `Alt + Q` 极速框选屏幕**，通过内置离线 OCR 瞬间提取英文！
2. **懂梗、懂放置游戏机制**：NGU IDLE 充满了 4G 作者的自嘲恶搞（如 *crappy*, *doodad*, *shenanigans*）以及核心机制术语（*Cap, Power, Bars, Rebirth, Wandoos, Diminishing Returns, Multiplicatively*）。普通翻译软件查不出机制含义，而本软件内置**专属梗与机制解析库**。
3. **挂机利用碎片时间复习**：等资源跑条（Tick）的挂机闲暇时间，可以在浮窗里翻看**挂机微测验（Flashcards）**，利用情境记忆轻松掌握高频英语。

---

## 🚀 核心功能一览

* **📸 屏幕快捷框选取词（Alt + Q）**：无论游戏在全屏还是窗口化，随时按下快捷键框选，半秒提取中英释义。
* **💡 NGU 专属机制 & 玩梗解析**：自动检测文本中的黑话与自嘲道具命名，告诉你背后的游戏机制与笑点。
* **🔊 原生语音发音**：调用 Windows 朗读引擎，边玩边听地道发音。
* **📚 挂机生词本**：遇到的生词一键【➕】收藏，自动附带游戏原句和机制解释；支持一键导出为 **Markdown** 或 **Anki 卡片 (CSV)**。
* **⚡ 放置微测验 (Spaced Repetition)**：游戏挂机刷图时翻牌刷词，强化长期记忆。
* **📖 NGU 百科词典**：预置 30+ 放置游戏核心术语、装备词缀与常用词。

---

## 🎮 使用方法

1. 打开游戏 **NGU IDLE**。
2. 双击运行目录下的 **`启动NGU英语伴侣.bat`**（或在终端运行 `python app.py`）。
3. 工具启动后默认保持在屏幕顶层，你可以把它拖到游戏窗口的旁边。
4. 在游戏中看到不认识的装备说明或技能时：
   * 按下全局快捷键 **`Alt + Q`**（或点击界面上方的【📸 框选游戏取词】）。
   * 鼠标拖拽框选游戏里的英文段落，松开鼠标即可。
   * 查看解析、听发音、点击【➕】收录进生词本！
